# TradeCore – Block des Tages für GrieferGames

> **Deutsch** · [English version below](#english)

[TradeCore-Discord beitreten](https://discord.gg/vZvdnJwZrn) · [Video ansehen](https://www.youtube.com/watch?v=47JCMTcseyY)

TradeCore bringt den **Block des Tages (BdT)** direkt in Minecraft. Sieh den aktuellen BdT und seinen Gewinn, stimme über die benötigte Zeit ab und finde passende Blöcke mit einem konfigurierbaren Highlight in deiner Umgebung.

Die Mod wurde als leichtgewichtige Fabric-Client-Mod für die GrieferGames-Community entwickelt.

## Funktionen

- aktuellen **Block des Tages** und den Gewinn im Spiel anzeigen
- mit „schnell“ oder „langsam“ abstimmen
- Stimmenanzahl und prozentuale Verteilung ansehen
- neue BdT-Vorschläge direkt im Spiel erstellen
- Block- und Entity-Namen automatisch auflösen
- passende BdT-Blöcke in der Welt hervorheben
- Highlight-Farbe, Reichweite, Scanintervall und Partikelmenge einstellen
- BdT-Daten beim Betreten einer Welt automatisch laden oder manuell aktualisieren
- Discord-Konto direkt aus der Mod verknüpfen
- integrierten Taschenrechner und Chat-Rechner verwenden
- GrieferGames-Server-News im Chat optional ausblenden
- automatisch auf neue TradeCore-Versionen prüfen

Das Highlight begrenzt die Treffer auf nahe Blöcke und erzeugt die Partikel FPS-schonend.

## Standard-Tastenbelegung

| Taste | Aktion |
|---|---|
| Pfeil nach oben | BdT-Einstellungen öffnen |
| Pfeil nach rechts | Aktuellen BdT öffnen |
| Pfeil nach unten | BdT-Highlight umschalten |
| Umschalt + Z | Taschenrechner öffnen |

Alle Tasten können in den Minecraft-Steuerungseinstellungen geändert werden.

Für den Chat-Rechner einfach eine Rechnung wie `5+3`, `6*7` oder `100/5` in den Chat schreiben und **Tab** drücken.

## Voraussetzungen

- Minecraft **26.2**
- Fabric Loader **0.19.5** oder neuer
- Fabric API
- Java **25**

## Installation

1. Fabric Loader und Fabric API installieren.
2. Die TradeCore-JAR in den Ordner `.minecraft/mods` kopieren.
3. Minecraft mit dem Fabric-Profil starten.

> Die frühere Preisverwaltung ist seit TradeCore 2.2.0 nicht mehr Bestandteil der Mod.

# English

[Join the TradeCore Discord](https://discord.gg/vZvdnJwZrn) · [Watch the video](https://www.youtube.com/watch?v=47JCMTcseyY)

TradeCore brings the **Block of the Day (BdT)** directly into Minecraft. View the current block and its reward, vote on how long it took, and locate matching blocks nearby with a configurable world highlight.

The mod is a lightweight Fabric client mod created for the GrieferGames community.

## Features

- view the current **Block of the Day** and its reward in-game
- vote whether completing it was fast or slow
- see vote totals and percentage distribution
- submit new BdT suggestions directly in-game
- automatically resolve block and entity names
- highlight matching BdT blocks in the world
- configure highlight color, range, scan interval, and particle amount
- automatically load BdT data when joining a world or refresh it manually
- link your Discord account from inside the mod
- use the built-in calculator and chat calculator
- optionally hide GrieferGames server news in chat
- automatically check for TradeCore updates

The highlighter limits results to nearby blocks and uses performance-conscious particle rendering.

## Default key bindings

| Key | Action |
|---|---|
| Up Arrow | Open BdT settings |
| Right Arrow | Open the current BdT |
| Down Arrow | Toggle the BdT highlight |
| Shift + Z | Open the calculator |

All keys can be changed in Minecraft's control settings.

For the chat calculator, type an expression such as `5+3`, `6*7`, or `100/5` into chat and press **Tab**.

## Requirements

- Minecraft **26.2**
- Fabric Loader **0.19.5** or newer
- Fabric API
- Java **25**

## Installation

1. Install Fabric Loader and Fabric API.
2. Place the TradeCore JAR in `.minecraft/mods`.
3. Launch Minecraft using the Fabric profile.

> The former price-management features are no longer part of the mod as of TradeCore 2.2.0.
